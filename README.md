Java JDBC Learning Project

About

A beginner-friendly Java project demonstrating database connectivity using JDBC and MariaDB.

Technologies

- Java
- JDBC
- MariaDB
- Maven

Database Details

- Database: "lost_found_db"
- Table: "students"

Features (CRUD Operations)

- INSERT – Add student records.
- SELECT – Display student records.
- UPDATE – Modify student details.
- DELETE – Remove student records.

Learning Outcomes

- Connecting Java with MariaDB.
- Executing SQL queries using JDBC.
- Performing CRUD operations.
